# BhavPath - India's First Placement Readiness Predictor by Ponduri Bhavya Sri

**Live App:** https://bhavpath.streamlit.app
**GitHub Pages:** https://ponduribhavyasri04.github.io/BhavPath/

BhavPath is a placement predictor and placement readiness checker built for B.Tech CSE students. It helps students analyze their placement DNA based on B.Tech percentage, skills and college.
